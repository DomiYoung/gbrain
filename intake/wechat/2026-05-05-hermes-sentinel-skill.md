# Hermes Sentinel: 让 Hermes 脱胎换骨的 skill

## 核心问题

每次帮朋友装完 Hermes，他们都会问同样的问题 — "靠谱吗？会不会偷偷烧钱？插件安全吗？"还有一个更普遍的问题：很多人不知道怎么跟 AI 描述需求，对着对话框憋半天，敲两个字 — "太暗"。

## Sentinel 是什么

一个让 Hermes 从"你问它答的工具"变成"会自己照顾自己的助手"的 skill。

安装：`hermes skills install hermes-sentinel`

## 三大核心功能

### 1. Intent Translator（意图翻译器）

解决"用户不知道怎么说，AI 不知道怎么做"的问题。

在 Hermes 处理消息之前，Sentinel 先拦截。如果检测到输入很短、很模糊（"太暗""乱码""太慢"），它不是让 Hermes 猜，也不是反问"请具体描述"——它直接把这些模糊输入翻译成清晰、可执行的专业指令。

| 你说 | Sentinel 翻译后 Hermes 收到的 |
|---|---|
| 太暗、太亮、不好看、太乱、看不清 | 具体视觉调整指令（亮度、对比度、缩略图可读性） |
| 乱码、报错、跑不起来、没反应 | 编码修复、调试步骤、运行时修复指令 |
| 太慢、太贵、连不上、没输出 | 性能诊断、成本检查、网络排查指令 |
| 太啰嗦、太短、看不懂 | 简化、扩展、重写指令 |

这跟"对齐 skill 标准"有本质区别。Skill 记录的是你试出来的正确答案，Intent Translator 补的是"你不知道怎么说的那道坎"。

### 2. 两道防线：兜底常见翻车场景

**防线一：插件自动安检**
安装前自动扫描硬编码密钥、高危命令、恶意模式。致命风险直接拦截，低风险静默放行。

**防线二：API 用量实时追踪**
每次 API 调用后自动记录模型和 Token 用量。日常沉默，超预算才提醒："今天 API 花了 $0.52，快到预算了。"支持价格表配置后可估算费用。

### 3. 五个后台守护模块（定时任务驱动，全平台通用）

所有模块遵循同一原则：**先自动解决，解决不了再请你帮忙**。每条消息最多两句话，同类型问题每天最多提醒 3 次。

| 模块 | 频率 | 功能 |
|---|---|---|
| 🖥️ 硬件监控 | 每10分钟 | 内存、CPU、磁盘、GPU。预警自动清理，危险提醒。不同平台调用各自系统 API |
| 🌐 网络守护 | 自动 | 识别网络类型（直连/代理/VPN/企业内网），异常时诊断根因 + 给可操作建议。不报技术指标，只说问题在哪、怎么修 |
| 🔧 故障自愈 | 自动 | 检查已安装 skill 的完整性和日志文件的可写入状态。发现问题自动修复，修不了才通知 |
| 🛡️ Skill 安全审查 | 安装前 | 致命/严重风险自动拦截，低风险静默放行。同时检测配置冲突并给出合并建议 |
| 📊 Token 用量记录 | 每次 API 调用 | 提取输入/输出 token 数，支持价格表配置后估算费用 |

## 跨平台能力

macOS / Linux / Windows 全平台通用。跨平台能力由内置的 OS 检测层自动适配，不同系统下行为一致。

## 关键设计原则

- **先自动解决，解决不了再请你帮忙**
- 每条消息最多两句话
- 同类型问题每天最多提醒 3 次
- 装完自动激活，零配置
- 通过 Hermes 原生插件机制自动触发，不需要额外装东西
